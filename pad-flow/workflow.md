# Power Automate Desktop Batch Conversion Flow

This document describes the Power Automate Desktop (PAD) automation flow for OFD batch conversion.

## Prerequisites

- Windows 10/11
- Microsoft Power Automate Desktop (installed)
- JDK 21+ (installed and added to PATH)
- `ofd-to-image-converter-1.0.0.jar` built

## Flow Configuration

### Paths to Update

Update these paths in the PAD flow to match your environment:

| Variable/Step | Default Path | Description |
|---------------|--------------|-------------|
| ZIP source dir | `C:\Users\...\Desktop\Automation\CompressedOFD\` | ZIP files to convert |
| Extract dir | `C:\Users\...\Desktop\Automation\OFDToPDF\` | ZIP extraction target |
| Launch script | `D:\...\原神启动.bat` | Converter launch script |

### Flow Steps

#### Phase 1: File Acquisition & Extraction (Step 1-5)

| Step | Action | Description |
|------|--------|-------------|
| 1 | Get files in folder | Get `*.zip` files from source → `Files` |
| 2 | For each `CurrentItem` in `Files` | Loop through ZIP files |
| 3 | Extract ZIP file | Extract `CurrentItem` to working dir |
| 4 | End | End loop |
| 5 | Get subfolders | Get all subfolders from working dir → `Folders` |

#### Phase 2: Launch Converter (Step 6)

| Step | Action | Description |
|------|--------|-------------|
| 6 | Run application | Execute `start.bat` → `AppProcessId` |

#### Phase 3: GUI Automation (Step 7-14)

| Step | Action | Description |
|------|--------|-------------|
| 7 | For each `CurrentItem1` in `Folders` | Loop through subfolders |
| 8 | Comment | "Auto-generated by recorder" |
| 9 | Fill text field | Enter `CurrentItem1` into `JText` (source path) |
| 10 | Fill text field | Enter `CurrentItem1` into `JText2` (output path) |
| 11 | Click button | Click `JPush Button '转换'` |
| 12 | Wait for window element | Wait for `JPush Button '确定'` to be available |
| 13 | Click button | Click `JPush Button '确定'` |
| 14 | End | End loop |

#### Phase 4: Cleanup & Notification (Step 15-27)

| Step | Action | Description |
|------|--------|-------------|
| 15 | For each `CurrentItem1` in `Folders` | Loop through subfolders |
| 16 | Get files | Get `*.ofd` files → `Files2` |
| 17 | Delete files | Delete `Files2` |
| 18 | End | End loop |
| 19 | Get subfolders | Get subfolders from working dir → `Folders` |
| 20 | For each `CurrentItem2` in `Folders` | Loop through subfolders |
| 21 | Run PowerShell | Execute conversion script → `PowershellOutput` |
| 22 | End | End loop |
| 23 | For each `CurrentItem3` in `Folders` | Loop through subfolders |
| 24 | Get files | Get `*.png` files → `Files3` |
| 25 | Delete files | Delete `Files3` |
| 26 | End | End loop |
| 27 | Display message | Show "Conversion Complete" dialog |

## Important Notes

1. **GUI Component Names Must Not Change** — `JText`, `JText2`, `JPush Button` are Java Swing component names. If you modify component names in the GUI code, the PAD flow will fail.
2. **Window Title** — Ensure the OFD converter window title matches what's recorded in the PAD flow.
3. **Timing Issues** — If conversion takes longer, increase the wait timeout in Step 12.
4. **Chinese Paths** — PAD handles Chinese paths well, but avoid special characters in paths.
